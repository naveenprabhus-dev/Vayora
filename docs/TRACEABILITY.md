## Verification Scope & Remaining Limitations

- **Firebase Rules Runtime Emulator**: Static security-rule linting (`npm run lint:rules`) passes with 0 errors; adversarial runtime execution of `infrastructure/firebase/firestore.rules.test.ts` requires a JVM runtime (`java` is unavailable in this container environment).
- **Live Upstream Calls**: Automated unit, integration, and E2E suites inject deterministic Open-Meteo, Firebase token-verifier, and Gemini SDK test doubles so live third-party quota/latency is not exercised in CI.
- **Accessibility Testing**: Automated `@axe-core/playwright` and Vitest `axe-core` WCAG 2.2 AA scans pass with `0` violations across desktop and mobile flows; full manual screen-reader (NVDA/JAWS/VoiceOver) and extended keyboard-only verification remain required prior to production release.
- **Open-Meteo Licensing**: Open-Meteo endpoints remain isolated behind swappable server adapters with `CC BY 4.0` attribution; commercial, hackathon, or public demo hosting requires confirming applicable Open-Meteo license terms.
